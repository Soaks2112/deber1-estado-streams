# Parte A — Contador

Proyecto Flutter con persistencia en SharedPreferences. La rama Git selecciona la implementación de presentación: `version/setstate`, `version/riverpod` o `version/bloc`.

```sh
flutter pub get
flutter run
```

Desde la raíz del repositorio, consulta [RESPUESTAS.md](../RESPUESTAS.md) y usa los comandos Git que aparecen allí para comparar las ramas.
