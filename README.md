# Deber 1: estado y streams en Flutter

El repositorio contiene dos proyectos Flutter independientes. En Parte A, las ramas `version/setstate`, `version/riverpod` y `version/bloc` contienen la misma app con distinta capa de presentación; todas parten de `main` y conservan los mismos archivos `domain/` y `data/`. La Parte B está en `main` y se conserva en cada rama.

Para completar los proyectos Flutter en un equipo con Flutter instalado, desde cada carpeta corre `flutter create --platforms=android,ios,web .` y después `flutter pub get`. Ejecuta `flutter run` desde el proyecto requerido. No se sube un video de demostración porque debe grabarse durante una prueba real en un teléfono.

Consulta [RESPUESTAS.md](RESPUESTAS.md) para las respuestas y las observaciones que aún requieren ejecutar las aplicaciones.
